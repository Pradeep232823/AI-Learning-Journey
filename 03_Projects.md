# Project Standards

Every project must include:

- README.md
- Requirements
- Folder Structure
- Installation Guide
- Features
- Screenshots (if applicable)
- Future Improvements
- GitHub Repository

---

# Completion Criteria

A project is considered complete only if:

- Working correctly
- Code reviewed
- GitHub pushed
- Documentation completed
- README written
- Improvements discussed

# Learning Strategy

Whenever learning a new technology:

1. Read official documentation first.
2. Build a small example.
3. Build a real project.
4. Ask questions.
5. Document what was learned.

---

# Resource Rules

- Prefer official documentation.
- Prefer practical examples.
- Avoid tutorial overload.
- Learn only what is required for the current project.
- Update this document whenever a high-quality resource is discovered.

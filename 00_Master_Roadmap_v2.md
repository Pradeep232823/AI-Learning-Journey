# Mission

Transform from a student with foundational programming knowledge into an AI Engineer capable of designing, building, deploying, and explaining production-style AI applications.

The primary objective is **employability**, not simply completing a course.

---

# End Goal

By the end of this bootcamp, I should be able to:

- Build complete AI applications independently.
- Develop production-style AI backends.
- Integrate LLM APIs into real applications.
- Build Retrieval-Augmented Generation (RAG) systems.
- Build AI agents and workflows.
- Deploy AI applications.
- Maintain a professional GitHub portfolio.
- Explain engineering decisions confidently.
- Perform well in AI Engineering interviews.

---

# Core Philosophy

This bootcamp follows an **Engineering First** approach.

We focus on:

- Building instead of memorizing.
- Understanding instead of copying.
- Solving engineering problems.
- Writing maintainable code.
- Creating production-ready projects.
- Learning concepts only when they improve engineering ability.

Learning is measured by **what I can build**, not by how many tutorials I finish.

# Learning Cycle

Every topic follows the same cycle.

```text
Learn
    ↓
Understand Why
    ↓
Mini Project
    ↓
Debug
    ↓
Improve
    ↓
Code Review
    ↓
GitHub
    ↓
Notes
```

Notes are written **after** understanding and implementation.

# Mentor Responsibilities

The mentor will:

- Teach from first principles.
- Explain the "why" before the "how."
- Prioritize industry-relevant topics.
- Review code honestly.
- Recommend best practices.
- Design production-style projects.
- Simulate interview questions.
- Encourage independent problem-solving.

---

# Student Responsibilities

The student will:

- Build every project personally.
- Study consistently.
- Ask questions when blocked.
- Debug before requesting solutions.
- Maintain GitHub regularly.
- Track progress honestly.
- Complete assignments before moving forward.
- Focus on understanding instead of memorization.

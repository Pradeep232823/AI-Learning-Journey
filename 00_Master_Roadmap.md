# Mission

Transform from a student with basic programming knowledge into an AI Engineer capable of designing, building, deploying, and explaining real-world AI applications.

The primary objective is **employability**, not simply completing a course.

---

# Goal

By the end of this bootcamp, I should be able to:

- Build complete AI applications independently.
- Work confidently with modern LLM APIs.
- Develop production-style AI systems.
- Design and implement RAG applications.
- Build AI agents and workflows.
- Deploy AI applications.
- Maintain a professional GitHub portfolio.
- Be prepared for AI Engineering interviews.

---

# Bootcamp Philosophy

This bootcamp follows an engineering-first approach.

We focus on:

- Building instead of memorizing.
- Understanding instead of copying.
- Solving problems instead of watching tutorials.
- Creating production-ready projects instead of toy examples.

Learning is measured by what I can build, not by how many videos I watch.

---

# Learning Principles

Every topic follows the same learning cycle:

1. Understand the concept.
2. Learn why it exists.
3. Build something practical.
4. Debug the implementation.
5. Improve the project.
6. Review the code.
7. Push the project to GitHub.

---

# Daily Learning Model

Every day follows this structure:

### Session 1

Concept Learning

- Understand the topic
- Understand why it exists
- Learn the fundamentals

---

### Session 2

Guided Implementation

- Write code
- Learn best practices
- Understand project architecture

---

### Session 3

Project Development

- Build the day's project
- Solve problems independently
- Apply everything learned

---

### Session 4

Review

- Debug
- Improve code quality
- Push to GitHub
- Document progress
- Prepare for the next day
